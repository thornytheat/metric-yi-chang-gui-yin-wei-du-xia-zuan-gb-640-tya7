# 样例数据 anomalyattr

`sample_data/` 里 7 个文件，全部由确定性脚本生成（无随机数），可直接用于演示与测试。

| 文件 | 字节 | 编码 | 用途 |
|---|---:|---|---|
| `daily_metrics_dirty.csv` | 83K | UTF-8 带 BOM | 主样例：4 门店 × 3 渠道 × 84 天（2026-08-30 → 2026-11-21） |
| `daily_metrics_values.csv` | 627 | UTF-8 | 值归一：千分位、全角数字、单位后缀、哨兵 |
| `daily_metrics_gb18030.csv` | 9.8K | GB18030 | 编码回退：2 门店 × 3 渠道 × 21 天 |
| `daily_metrics_truncated.csv` | 2.5K | UTF-8 | 末行被截断（4 列，且无换行） |
| `daily_metrics_header_only.csv` | 93 | UTF-8 | 只有表头 |
| `daily_metrics_blank.csv` | 102 | UTF-8 | 只有表头 + 3 行全空 |
| `review_marginal.csv` | 24K | UTF-8 | 复盘样例：3 门店 × 2 渠道 × 62 天（2026-09-20 → 2026-11-20），含边际跌幅与同渠道同步下滑 |

## 主样例里埋的脏点

- 编码：UTF-8 BOM；另有一个 GB18030 文件走同一条解码链。
- 时区：快照时间混用 `+08:00`、`Z`、无偏移三种写法。
- 缺桶：`H04/member` 缺 `2026-10-05`、`2026-10-06`，缺失点计入点账。
- 重复快照：4 个键存在更晚快照（被覆盖），1 个键同一快照时间给出两个净收入（整键隔离）。
- 迟到：10 个点在 3 天后补报（窗内），1 个点在 9 天后补报（超窗）。
- 脏值：3 行房价为 `N/A` / `-` / `未知`，1 行净收入为负，1 行超售 2 倍，1 行已售写小数，1 行业务日为 `2026-13-01`，1 行快照为 `not-a-time`，1 行列数多一列。
- 注入异常：`H02/ota` 11-17 → 11-18 连续两天跌 45%，`H01/member` 11-14 → 11-15 连续两天跌 32%，`H03/direct` 11-19 单点冲高 62%（只算候选）。

## 复盘样例里埋的点

- 边际跌幅：`R01/ota` 11-14、11-15 连跌，基准组合确认、阈值提到 4.5 就消失（`unstable`）。
- 同渠道同步：`R02/ota` 与 `R03/ota` 11-18、11-19 同向下滑，归为一组同批异常。
- 节假日偏移：休息日基线里含 10 个节假日点（中秋 3 天 + 国庆 7 天），普通周末被判偏低，复盘标 `R_HOLIDAY_THIN` 并降置信。

## 复现

```bash
curl -s -X POST -F sample=daily_metrics_dirty.csv http://127.0.0.1:18209/api/import
curl -s http://127.0.0.1:18209/api/reconcile
```

重复执行同一条命令得到的 `run_id`、行数与合计都不变（同源幂等）。
